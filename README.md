# Customer Performance Analysis Dashboard

## Project Overview

This project analyzes customer performance using the Superstore dataset in Power BI. The dashboard compares customers using sales, profit, profit margin, sales growth, and average order value.

## Objective

To evaluate customer performance using multiple KPIs and understand differences across regions and states.

## Tool Used

Power BI

## Key KPIs

* Total Sales
* Total Profit
* Profit Margin %
* Sales Growth %
* Average Order Value

## Dashboard Visuals

* Customer Sales Ranking
* Sales vs Profit
* Average Order Value by Customer
* Sales Growth by Customer
* Customer Performance Ranking Table

## Filters

* Order Date
* State
* Region
* Customer Name

## Key Insights

* Identified customers generating high sales.
* Compared sales performance with profitability.
* Analyzed customer sales growth.
* Compared average order values across customers.
* Examined performance across different regions and states.

## Recommendations

1. Focus on high-sales customers.
2. Improve low-profit customer performance.
3. Increase average order value.
4. Monitor declining sales growth.
5. Compare performance across regions and states.

## Conclusion

The dashboard provides a concise view of customer performance and helps identify sales, profitability, growth, and order-value patterns for business analysis.
